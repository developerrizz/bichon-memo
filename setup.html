비숑 설치하기

아이폰에서 이 페이지를 열고 순서대로 따라 해 주세요.

연결 코드가 없는 주소예요. 노트북에서 받은 설치 링크로 다시 열어 주세요.

1비숑 앱을 홈 화면에 놓기

  1. 아래 비숑 열기를 눌러요. (사파리에서 열려야 해요)
  2. 화면 아래 공유 버튼(네모에 위쪽 화살표)을 눌러요.
  3. 홈 화면에 추가 → 오른쪽 위 추가를 눌러요.
비숑 열기

이제 홈 화면의 비숑 아이콘을 누르면 바로 말을 걸 수 있어요.

2배경화면 위젯 놓기

  1. 앱스토어에서 무료 앱 Scriptable을 설치해요.
  2. 아래 위젯 코드 복사를 눌러요.
  3. Scriptable을 열고 오른쪽 위 +를 눌러 빈 화면에 붙여넣기 해요.
  4. 맨 위 제목(Untitled Script)을 눌러 이름을 비숑으로 바꾸고 Done을 눌러요.
  5. 홈 화면 빈 곳을 길게 눌러 왼쪽 위 편집 → 위젯 추가 → Scriptable 검색 → 작은 크기나 중간 크기를 추가해요.
  6. 추가된 위젯을 길게 눌러 위젯 편집 → Script에서 비숑을 골라요.
Scriptable 설치하러 가기

위젯은 아이폰이 정한 간격(보통 15분~1시간)으로 바뀌어요. 시간대, 대기 중인 메모, 노트북 답장에 따라 비숑 모습과 말이 달라지고, 누르면 비숑 앱이 열려요.

3이렇게 써요

  1. 생각난 아이디어나 할 일을 비숑한테 말하듯 적고 보내기.
  2. 노트북이 30분마다 확인해서 처리하거나 기억해 두고, 비숑한테 답장을 남겨요.
  3. 급한 건 급해요를 켜고 보내면 노트북에 바로 알림이 떠요.
  4. 노트북이 꺼져 있으면 메모는 안전하게 쌓여 있다가 켜지면 처리돼요.
